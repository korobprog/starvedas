# План доработок расписания обрядов StarVedas

## Цель

Сделать работу с расписанием обрядов удобной для администратора и понятной для клиента: дата должна сохраняться, быть первой и заметной в карточке, обряды должны автоматически выстраиваться по календарю, а админка должна давать обратную связь после сохранения.

## Этап 1 — критичные исправления

- [x] Зафиксировать план работ в Markdown-файле.
- [x] Проверить сохранение даты `ServiceOption.eventStartsAt` при создании и редактировании обряда.
- [x] Сделать отображение даты в начале публичной карточки обряда.
- [x] Сделать дату крупной и визуально заметной на мобильном экране.
- [x] Убрать ощущение дублирования даты: описание не должно быть основным местом даты.
- [x] Автоматически сортировать обряды по дате проведения.
- [x] Если дата отсутствует, показывать такие обряды после датированных.
- [x] Добавить сообщение об успешном сохранении в админке.
- [x] Добавить состояние кнопки во время сохранения, где это возможно.
