## 5. Подключение SMTP к сайту

SMTP-данные для подключения:

```text
Email: service@chintamanidhama.ru
SMTP: smtp.jino.ru
Port: 587
Encryption: STARTTLS
Login: service@chintamanidhama.ru
Password: пароль от ящика
```

Альтернативный вариант:

```text
SMTP: smtp.jino.ru
Port: 465
Encryption: SSL
```

Задачи:

- [x] Подключить SMTP в сайте / backend / админке
- [ ] Проверить отправку тестового письма через сайт
- [ ] Проверить письмо восстановления пароля
- [ ] Проверить письмо после успешной оплаты
- [ ] Проверить письмо при ошибке оплаты
- [ ] Проверить письмо с чеком или ссылкой на чек

Технически добавлено:

- SMTP-настройки берутся из переменных `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL`, `SMTP_FROM_NAME`.
- Тест SMTP: `GET /api/email/test` проверяет подключение, `POST /api/email/test` отправляет тестовое письмо. Доступ только для admin / super admin.
- Письма отправляются без блокировки основного сценария: ошибка SMTP логируется, но регистрация / заказ / оплата не падают.

## 7. DMARC после проверки

Сейчас DMARC находится в мягком режиме:

```text
p=none
```

После стабильной работы можно усилить защиту:

- [ ] Рассмотреть переход на:

```text
p=quarantine
```

- [ ] После полной уверенности можно рассмотреть:

```text
p=reject
```
